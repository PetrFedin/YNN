## 1. Архитектура модели v0.1

```
                    ┌─────────────────────┐
                    │   SHARED (не делим) │
                    │ Payroll / Rent / …  │
                    │ Tax cash            │
                    └──────────┬──────────┘
           ┌───────────────────┴───────────────────┐
           ▼                                       ▼
   A. MD / couture                          B. Goods
   Rev = DDS Salon+Shop                     Rev = costed sales
   COGS_A = ??? (дыра)                      COGS = FILE/W3
   Contribution_A = ???                     GM_B = Rev−COGS
```

Правила v0.1:
1. A и B считаются **раздельно**.  
2. Shared opex **не** вычитается из одного контура как «убыток канала».  
3. TSUM в B всегда dual.  
4. Goods operating result — **справочный антипример**, не KPI.
