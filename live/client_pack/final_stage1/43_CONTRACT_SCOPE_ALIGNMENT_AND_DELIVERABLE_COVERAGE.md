# 2. Как это соответствует исходному коммерческому предложению

Исходное коммерческое предложение представляло проект как пять последовательных блоков:

1. первичная диагностика;
2. финансовая диагностика и оборотный капитал;
3. операционная диагностика;
4. разработка целевой модели;
5. программа трансформации и внедрения.

Финальная двухэтапная терминология не сокращает этот периметр.

Фактически:

- текущий **Этап 1** включает содержание исходных блоков 1–3 и проектирование существенной части блока 4;
- текущий **Этап 2** превращает спроектированную модель в работающую систему и покрывает внедренческую часть исходных блоков 4–5.

> **Таким образом, «Этап 1» в финальном пакете нельзя сопоставлять только с первоначальным первым блоком коммерческого предложения. Это весь комплекс диагностической работы и проектирование целевой модели.**

# 4. Что означает «готово» в диагностическом проекте

Диагностический результат и внедрённый процесс — разные категории.

Финальный пакет использует пять уровней:

1. **Подтверждённый диагностический факт** — поддержан источником и методикой.
2. **Диагностический вывод** — причинная интерпретация подтверждённых фактов.
3. **Потенциальный резерв / exposure** — зона эффекта, которая требует дополнительного подтверждения.
4. **Спроектированное решение** — target process / control / model.
5. **Реализованный эффект** — подтверждается только после внедрения и financial bridge.

> **Разработанная модель не равна внедрённой модели. Выявленный резерв не равен экономии. Высокая маржа не равна свободному cash.**
