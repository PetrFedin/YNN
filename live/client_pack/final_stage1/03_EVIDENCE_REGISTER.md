## Правила чтения

- **CONFIRMED** — факт подтверждён согласованными источниками.
- **STRONG INDICATION** — сильное подтверждение, но требуется дополнительное закрытие.
- **PARTIAL** — подтверждена только часть вывода.
- **NOT PROVEN** — данных недостаточно.
- **REFUTED** — прежняя интерпретация опровергнута новыми данными.

## Обязательное правило финального отчёта

Каждый числовой вывод, который может повлиять на решение собственников, должен содержать:

1. период;
2. источник;
3. метод расчёта;
4. статус подтверждения;
5. ограничение;
6. допустимое управленческое применение.
