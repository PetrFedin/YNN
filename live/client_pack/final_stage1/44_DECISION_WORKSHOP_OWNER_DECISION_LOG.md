# 3. Контрольные точки

## 0–30 дней

- 13-недельный денежный прогноз;
- классификация банковских операций;
- WIP и стоимость завершения;
- документное закрытие B2B-расчётов;
- решения по запасу класса A;
- правила остановки новых утечек.

## 31–90 дней

- пилот 20–30 заказов;
- матрица сложности;
- план/факт экономика;
- переделки;
- мощность;
- двухконтурный ОПУ;
- канальная экономика.

## 90–180 дней

- управленческий баланс;
- D+10 два месяца подряд;
- RACI;
- налоговые сценарии;
- панель управления;
- регулярный реестр подтверждённого эффекта.

---

# 4. Правило признания экономического эффекта

Потенциальный резерв не считается реализованным эффектом.

Эффект признаётся только по цепочке:

`базовый уровень → действие → доказательство → финансовый мост → исключение двойного счёта → реализованный результат`.
