## 2. Три ложных вывода (запрещены)

### Ложь №1 — «Маржа компании ~53%»
Берём goods GM 52.8% и вешаем на весь бизнес, включая МД.

| | |
|--|--|
| Почему ложь | У МД **нет** product COGS в staging; 53% — свойство costed goods |
| Что будет на слайде | «Здоровая маржа 53% на ~300M» |
| Реальность | Маржа МД **не измерена** в этой модели |

### Ложь №2 — «YANINA убыточна −74% / −54M»
Берём goods-only operating YEAR_2025.

| | |
|--|--|
| Почему ложь | В знаменателе/базе только **72.9M** товара; **232M МД** не в выручке моста; opex при этом почти весь |
| Что будет на слайде | «Операционный убыток −74%» |
| Реальность | Это артефакт **неполной базы выручки**, не вердикт по компании |

### Ложь №3 — «Наивная склейка: выручка 305M, opex+tax 92.5M → всё ок / не ок»
Складываем A+B revenue, вычитаем весь opex+tax, **не имея COGS МД**.

| Показатель | «Наивная» арифметика |
|------------|---------------------|
| Revenue A+B | 232.6 + 72.9 = **305.5M ₽** |
| (−) Goods COGS | −34.4M |
| (−) MD COGS | **??? = 0 в модели** ← дыра |
| (−) Opex | −73.9M |
| (−) Tax | −18.6M |
| «Result» | **выглядит как угодно** в зависимости от фантазии по MD COGS |

Любой «result» здесь — **не отчёт**, а упражнение. Публиковать нельзя.

## 3. Правильная рамка для 2025 (что можно сказать вслух)

1. **Контур A (МД):** денежный доход ~2.32–2.33M EUR сверен с DDS (gap −6.2k EUR за год). Unit-economics кутюра в этой модели **нет**.  
2. **Контур B (товар):** costed GM ~52.8% на 72.9M; TSUM смотреть dual (37.9% vs 87.9%).  
3. **Opex/tax 2025 (~92.5M)** относятся к операционному периметру ИП/группы и **не доказаны** как «съеденные только товаром» или «только МД».  
4. Пока нет Phase C (режим ЦУМ + политика opex O0/O1…) — **нет** единого operating % компании.

## 4. Чувствительность TSUM (если комиссия в COGS)

На полном periметре (не только 2025):  
commission_proxy ≈ FILE COGS − W3 ≈ **60.9M ₽** → reported GM 37.9% vs product 87.9%.

| Если Меркушина скажет… | Следствие для отчётов |
|------------------------|------------------------|
| «Комиссия в cost cards, % = X» | Unified → режим **C1** (gross − commission line; product COGS) |
| «Комиссия только в агентских/cash» | Reported 37.9% **завышает** COGS; чинить margin на product; cash net-rate ок |
| «Не знаю / по-разному по годам» | Держать dual view; Phase C = **no-go** |

Без ответа — в memo всегда два числа TSUM.
