## 3. Насколько этого хватает — по целям

### A. Полноценный анализ бизнеса
| Подцель | Готовность | Комментарий |
|---------|------------|-------------|
| Понять структуру юрлиц/каналов/owners | **90%** | Бриф + BUSINESS_STRUCTURE |
| Увидеть, где деньги сходятся/не сходятся | **75–85%** | Gate + recons |
| Товарная маржа и исключения | **70–80%** | С оговорками TSUM/quarantine |
| Экономика инд. пошива (маржа/час/заказ) | **20–30%** | Есть cash, нет COGS/времени |
| Единый P&L / рентабельность компании | **15–25%** | Методологически нельзя без Phase C go |
| Сравнение с бюджетом | **40%** | Бюджетные файлы есть, склейка слабая |

### B. Предложения по трансформации и оптимизации
| Тип рекомендаций | Можно сейчас? | Условие |
|------------------|---------------|---------|
| **Data / учёт / governance** (что вести, кто owner, dual TSUM, два контура, gate) | **Да — высокая уверенность** | Уже в memo/briefing/Phase C |
| **Процессы cash** (эквайринг, B2B settle, DDS лаг) | **Да — operational** | Нужны файлы owners для закрытия |
| **Оптимизация канала ЦУМ / агентской модели** | **Осторожно** | Сначала ответ Меркушиной (C1/C2/C3) |
| **Оптимизация FTE / payroll / цех** | **Слабо** | Нет устойчивого person-level + driver аллокации |
| **Ассортимент / SKU / закупки** | **Частично** | Goods да; МД/фурнитура — нет |
| **Ликвидация Декор / LE redesign** | **Направление да** | Цифры wind-down 2026 — добить тегами |
| **«Закрыть/масштабировать канал X → +N млн»** | **Нет (нечестно)** | Нет единого P&L и MD contribution |

## 5. Что блокирует «полноценность»

1. **Метод:** нельзя читать goods operating (−58%/−74%) как компанию.  
2. **МД (~83%):** нет себестоимости заказа / остатков — главный пробел бизнес-анализа.  
3. **ЦУМ:** комиссия в COGS vs cash не зафиксирована.  
4. **IM/B2B cash:** 6 OPEN + 15 settle — дыры исполнения, не карты.  
5. **Opex allocation:** без O0/O1 политики любой «эффект оптимизации» по каналу будет спорен.

## 6. Практический вывод для вас

**Уже можно:**
- проводить диагностику и data-трансформацию (учёт, RACI, gate, dual reporting);
- давать приоритеты «что починить в данных и процессах» с owners;
- отделять факты от артефактов модели (антипример 2025).

**Ещё нельзя честно:**
- полный бизнес-кейс трансформации с гарантией эффекта в ₽;
- оптимизация «под P&L компании»;
- аудируемый SoT.

**Минимальный пакет, чтобы поднять готовность с ~60% → ~80% под трансформацию:**
1. Ответ Меркушиной (C1/C2/C3)  
2. DDS 2026-06 + IM×6 + B2B open  
3. Пилот Phase C v1 (**O0**, без аллокации opex) на 2025  
4. (Опционально) хотя бы proxy contribution МД: доход − прямые закупки/подряд по DDS статьям
