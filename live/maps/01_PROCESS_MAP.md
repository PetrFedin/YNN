## 3. End-to-end цепочки (algorithmic paths)

### Цепочка A (ядро)
`Клиент → (примерка вне 1С) → Производство/аутсорс → Оплата → МД workbook → SALES DDS → Банк/ДДС → Отчёт A`

Разрыв: себестоимость заказа, WIP, фурнитура.

### Цепочка B-IM
`Сайт → Отгрузка 1С → Эквайринг bank → recon_im → Margin IM → Отчёт B`

Разрыв: 6 OPEN months acquiring.

### Цепочка B-TSUM
`Передача → Sales ЦУМ → Cost card (с комиссией?) → Агентские bank → dual margin + net-rate`

Разрыв: единый режим комиссии (C1/C2/C3).

### Цепочка B-B2B
`Накладная → Settle → Bank match → open list`

Разрыв: 15 open / 2.51M.

### Цепочка затрат
`ФОТ/аренда/закупки → Expense/DDS → Bank → opex/payroll multi → Shared (не аллоцировано)`

Разрыв: split МД vs товар.
