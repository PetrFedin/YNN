# 06 — Карта ценности (value stream) и денег

Updated: 2026-07-27

---

## 1. Два контура ценности (не смешивать)

```
КОНТУР A — МД / услуги (ядро ~83%)
  Заказ → предоплата → производство → сдача → доплата
  Деньги: bank + DDS + МД workbook
  Маржа: НЕТ unit-econ в staging → только CF / заказы

КОНТУР B — Товары (IM + B2B + TSUM product view)
  Закуп/производство SKU → продажа → settle/комиссия
  Деньги: sales_lines + bank settle + cost cards
  Маржа: GM по каналам; dual TSUM
```

Операционный goods bridge −58%/−74% = **только контур B**, не P&L компании.

---

## 2. Поток денег (упрощённо)

```
Клиент / канал
    ↓
Продажа / заказ (SALES / МД)
    ↓
Банк IN (BANK) ←→ ДДС (CASH)
    ↓
Расход: payroll / opex / tax / cost / commission
    ↓
Банк OUT ←→ ДДС / TAX / EXP
```

Узкие места ценности:
1. **МД (P01)** — нет остатков заказов → нельзя увидеть WIP и маржу заказа  
2. **TSUM (P03)** — Excel COGS включает комиссию → ложная GM 37.9%  
3. **B2B (P04)** — open settle 2.51M → утечка CF  
4. **IM (P02)** — 6 мес BLOCKED → нельзя закрывать месяц без разбора  
5. **Ткани (P05) ~30M** — капитал без ABC → замороженные деньги  
6. **Фурнитура (P06)** — только в ДДС → WC невидим
