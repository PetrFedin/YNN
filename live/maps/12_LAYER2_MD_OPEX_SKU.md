### 1.3. Почему price_amount ≠ выручка МД

Salon `price_sum` 2025 в поле workbook ≈ **1.6M ₽** при DDS **232.6M ₽**.  
Разница порядок величины → поле **нельзя** читать как прайс/оборот.

**Вердикт (жёсткий):**  
для 2024–2025 unit-econ МД из workbook **неизвлекаем**.  
Любая «маржа заказа» из cost/price этих колонок будет **ложной**.  
SoT по МД остаётся: **payments ↔ DDS ↔ bank**, не order cost cards.

Зачем это важно для проекта: закрывает ложный путь «ещё чуть покрутим Excel — и будет contribution». Нужны **новые данные** (калькуляция заказа / BOM / учёт материалов на заказ).
